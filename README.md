# shuyang-zhao.github.io

Source for the personal academic website of Shuyang (Noah) Zhao, live at
<https://shuyang-zhao.github.io>.

Built with Jekyll on the [AcademicPages](https://github.com/academicpages/academicpages.github.io)
template (MIT license).

## Where things live

| What | Where |
| --- | --- |
| Home page text | `_pages/about.md` |
| Manuscripts under review / in revision | `_data/manuscripts.yml` |
| Publications, projects, talks, teaching | `_publications/`, `_projects/`, `_talks/`, `_teaching/` |
| CV | `_pages/cv.md` |
| Site styles | `_sass/layout/_custom.scss`, colors in `_sass/theme/_default.scss` |

## Local preview

```bash
bundle install
bundle exec jekyll serve -l -H localhost
```
